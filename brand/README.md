# Kit de Marca — ISSQA

Identidade visual da **ISS Software Quality Solutions** (issqa.com.br).
Símbolo: **Q-Check** — o Q de Quality com a cauda em checkmark.

## Cores

| Uso | Hex |
|---|---|
| Navy (principal) | `#021124` |
| Azul (accent / check) | `#149ddd` |
| Azul claro (subtítulo em fundo escuro) | `#7fc5e8` |
| Cinza (subtítulo em fundo claro) | `#5a6b7a` |

## Tipografia

- Wordmark: **Space Grotesk Bold** (Google Fonts)
- Texto de apoio do site: Ubuntu / Arial

## Regras rápidas

- Não alterar as cores do check (`#149ddd`) nem esticar o símbolo.
- Sobre fotos ou fundos coloridos, prefira as versões com fundo sólido.
- Área de respiro mínima: a altura do check ao redor de todo o lockup.
